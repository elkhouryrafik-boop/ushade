# Material archetype illustrations (`/materials/<id>.webp`)

Drop one **AI-generated illustration** per material archetype here. The MaterialPassportCard
loads `/materials/<id>.webp` automatically (deterministic, no rebuild). Missing files degrade
to an honest placeholder — never a broken image.

**Honesty:** these are labelled "AI illustration" in the UI. They are NOT real
reclaimed-stock photos. A real supplier `photoUrl` (when a feed provides one) always wins and
shows no AI badge. Never replace a real photo with an illustration.

Format: **webp**, ~600 px wide, 4:3-ish, neutral/studio background. Filenames are the exact
`data/materials.json` ids:
